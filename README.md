# IT Ticket Management System — Power Apps

A complete IT helpdesk / ticketing system built as a Power Apps Canvas app —
9 screens, live SLA tracking, role-based access, and automatic email
notifications via Office 365 Outlook.

▶️ [Full build walkthrough on YouTube]( https://youtu.be/UHQTdWVWDts ) 
🛒 [Get the ready-made template + setup docs]( https://dialforit.com/products/6a9914af55456cb98d94a92e )


## What it does

- **9 screens** — Dashboard, Tickets, Ticket Details, Create Ticket,
  SLA Monitor, Notifications, Reports, Users, Settings
- **Role-based navigation** driven entirely by a data table
  (Admin / Manager / Assigned Person / User) — no hardcoded role checks
- **Live SLA engine** — Critical (60 min), High (240 min), Medium (480 min),
  Low (1440 min), with On Track / At Risk / Breached states recalculated
  on every screen visit
- **Automatic email notifications** via the Office 365 Outlook connector —
  on ticket creation, assignment, priority change, status change,
  resolve and close
- **KPI dashboard** — 7-day ticket trend chart, category/priority
  breakdowns, filterable ticket list, SLA alerts queue
- **PDF export** — email individual tickets or full ticket lists as
  formatted, Outlook-safe HTML with optional PDF attachment
- **Runs on Power Apps collections** — no premium connector required to
  try it. Ships with 16 realistic seeded tickets so it works immediately
  on open.
